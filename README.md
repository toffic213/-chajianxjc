# 小剧场（Stage Theater）

这是一个 SillyTavern 客户端扩展：AI 回复完成后，用插件自己配置的 OpenAI 兼容 API 生成独立的小剧场。它不会调用酒馆的 `ctx.generate`，因此不会自动混入酒馆预设、角色卡或完整上下文。

如果安装后看不到悬浮球，请确认 GitHub 仓库的扩展根目录直接包含 `manifest.json`、`index.js`、`style.css`，而不是多套了一层 `stage-theater/` 文件夹；更新到新版本后卸载旧扩展并彻底重启酒馆。

## 安装

把 `stage-theater` 整个目录复制到：

```text
data/<你的用户名>/extensions/stage-theater/
```

确认目录内直接存在 `manifest.json`、`index.js`、`style.css`，重启酒馆后在扩展设置中启用。

## 使用

1. 点击右下角悬浮球，填写 API 地址、密钥和模型。地址可填根地址或带 `/v1` 的地址，插件会自动尝试两种组合。
2. 在“小剧场库”勾选一条或多条场景；“+”可新增场景，“导入预设”可选择 JSON 文件导入，也可在不支持文件选择的壳中粘贴 JSON。
3. 开启“AI 回复后自动生成”，或点击“立即生成”手动触发。
4. “发送最近对话”控制上下文开关，条数由“上下文条数”决定；“发送已启用世界书”会在当前酒馆壳提供世界书对象时附带它。

预设 JSON 支持单个对象或数组，常用字段如下：

```json
[
  { "name": "吐槽视角", "prompt": "让旁白用轻松语气吐槽刚才的回复。" },
  { "title": "番外", "content": "写一段不改变主线的幕后番外。" }
]
```

设置保存在浏览器 `localStorage` 和酒馆扩展设置中；最近一次输出会写入当前聊天的扩展元数据。API 请求失败时只在面板显示错误，不会阻塞酒馆聊天。

## 兼容范围

插件按交底文档中的 Tauri Tavern 约束编写：通过 `SillyTavern.getContext()` 获取上下文，优先监听 `MESSAGE_RECEIVED`，并对缺失的全局函数做降级处理。
