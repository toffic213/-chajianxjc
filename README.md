# stage-theater

SillyTavern 客户端扩展：在 AI 回复完成后，使用独立的 OpenAI 兼容 API 生成小剧场，并将结果保存到对应聊天消息的附属区域。

## 安装

将整个 `stage-theater` 文件夹放入：

```text
data/<用户名>/extensions/stage-theater/
```

然后在酒馆扩展设置中启用它。插件只依赖浏览器端 `fetch`，不会调用酒馆当前模型生成小剧场。

## 首次使用

1. 点击右下角悬浮球。
2. 在 API 页面新增或选择 API 档案，填写地址、Key 和模型名称。
3. 在提示词页面编辑、启用并勾选要使用的提示词。
4. 在上下文页面选择深度、合并/分别请求、是否发送已启用世界书条目。
5. 在总览页面打开全局自动生成。当前聊天可以单独选择“关闭”，默认跟随全局。

## 行为

- 只监听完整的正常 AI 回复、重新生成和 swipe 回复；中断不会触发。
- 多提示词默认合并为一次独立 API 请求；也可以切换为分别请求。
- 角色卡设定始终发送；上下文深度为 `0` 时只发送当前 AI 回复和用户上一条消息（若开关保持开启）。
- 世界书选项读取当前可访问的全局、角色绑定和聊天绑定世界书，只发送其中 `enabled` 条目。
- 结果保存到 AI 消息的 `extra.stage-theater`，随聊天记录持久化；重新生成成功后替换当前结果。
- 小剧场窗口位于对应 AI 消息下方，支持 HTML、内联 CSS、基础 JavaScript 沙盒渲染、折叠、重新生成、收藏、切换收藏、编辑和删除。
- API 档案、提示词库和插件全局设置同时保存到 `localStorage` 与酒馆扩展设置。

## 兼容性说明

插件按底稿约定使用 `SillyTavern.getContext()`、`ctx.chat`、酒馆事件、`ctx.chatMetadata.extensions.stage-theater` 和 `ctx.saveChat()`；同时对 TavernHelper 的角色卡与世界书读取接口做了可选兼容。若运行环境未提供相应接口，插件会保留可用功能并在控制台输出警告。
