## 🚀 功能清单

### 悬浮球面板（5个标签页）
1. **设置** - 启用/自动/深度/世界书/手动生成
2. **提示词** - 新增/编辑/删除/启用开关
3. **API** - 新增/删除/选用配置
4. **历史** - 查看所有生成记录
5. **收藏** - 查看收藏的小剧场

### 小剧场窗口操作
- **−** 折叠/展开
- **✏️** 编辑内容
- **❤️** 收藏本条
- **🔄** 重新生成（同消息）
- **🗑️** 删除此条

### 数据持久化
- API配置 localStorage
- 提示词库 localStorage  
- 收藏列表 localStorage
- 小剧场内容 msg.extra
