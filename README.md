# 小剧场生成器

酒馆客户端扩展。AI 回复完成后，插件使用独立 OpenAI 兼容 API 生成小剧场，并把结果显示在对应 AI 消息下方。

## 功能

- 悬浮球作为唯一设置入口。
- 独立 API 配置，不调用酒馆当前生成接口。
- 支持多个 API 档案、模型列表拉取、普通/流式请求。
- 提示词库支持分类、备注、排序、复制、导入、导出、启用/禁用。
- 支持全局启用和聊天级启用。
- 支持发送最近上下文、用户上一条消息、角色卡设定、已启用世界书条目。
- 小剧场结果保存到当前聊天，下次打开聊天可恢复显示。
- 小剧场窗口支持折叠、重新生成、收藏切换、复制、编辑、删除。
- 默认不执行 AI 返回的脚本；可在设置里打开沙盒脚本渲染。

## 安装

把整个 `stage-theater` 目录放到酒馆客户端扩展目录，例如：

```text
data/default-user/extensions/stage-theater/
```

或 Tauri Tavern 的第三方扩展目录。重启酒馆后，在扩展列表中启用。

## 使用

1. 点右下角悬浮球。
2. 在 API 页添加或填写 API 档案。
3. 在提示词页添加小剧场提示词并启用。
4. 打开总开关和当前聊天开关。
5. AI 正常回复完成后，小剧场会生成到对应消息下方。

## 注意

- API 地址按 OpenAI 兼容接口处理，会自动尝试 `/chat/completions` 和 `/v1/chat/completions`。
- 世界书读取依赖当前酒馆壳暴露的数据结构；插件会尽力读取已启用条目，拿不到时不会阻断生成。
- 角色卡设定同样采用兼容读取，能拿到多少发多少。
